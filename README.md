# ModernTech

A modern-technology content pack for **Software Inc.**: AI software, with phones, laptops, PCs, GPUs and CPUs planned.

Data mod only (TyD files, plus optional `.cs` scripts compiled by the game). No DLLs, no Harmony. Workshop-compatible.

## Install

1. Copy the `ModernTech` folder into the game's `Mods` folder:
   `<Steam>/steamapps/common/Software Inc/Mods/ModernTech`
2. Start the game, open **Options > Mods**, and make sure ModernTech is enabled.
3. Start a **new** game. New software types don't show up in old saves.

## Features

### Done
- **AI software types** (unlock 2011+), each with markets that grow as new tech arrives:
  - **AI Assistant**: voice assistant (2011), chat assistant (2022), personal agent (2026)
  - **Image Generator**: photo filter apps (2016), text-to-image (2022), text-to-video (2024)
  - **Coding Assistant**: smart autocomplete (2018), pair programmer (2021), coding agent (2025)
  - **Self-Driving Software**: driver assistance (2008), robotaxi (2020)

### Planned

- Laptop and PC furniture for the office (performance tiers)
